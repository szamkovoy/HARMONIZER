## Decision Log

- **2026-07-05:** Home reliably loads for **both** free and all paid tiers even when the cron pre-warm missed or Gemini is unavailable — root-caused a night where both paths hung/errored. Fixes:
  1. **Paid hang (`«Загружаю текст рекомендации на этот день»` stuck forever):** `callMonologue` (`services/aiClient.ts`) had **no client timeout**, so the cold-miss morning-recommendation hydration could wait indefinitely on a slow/held server connection, leaving `homeTextsLoading` true. Added `MONOLOGUE_TIMEOUT_MS = 105s` AbortController timeout — headroom over the server-side `generateGeminiJson` retry/fallback chain (primary `AI_MODEL_STANDARD/PREMIUM` up to 60s DeepSeek / 30s Gemini → `AI_MODEL_FALLBACK` up to 30–60s = ~90s worst case, model taken from `.env.local`, no hardcode) + DB; on timeout the secondary hydration catch clears loading and the card shows the deterministic fallback. Server may still finish and write cache → next open gets the real text.
  2. **Free hard error (`«Не удалось загрузить прогноз» / No global content available`):** the free path was all-or-nothing on the LLM. `ensureGlobalDailyContentRow` (`_legacy_web/app/api/_utils/ensureGlobalDailyContent.ts`) now **never throws on LLM failure** — the structural forecast + `math_level` are deterministic, so on a Gemini error it still upserts the row with deterministic fallback texts and `llm_model = null` (keeps `globalContentNeedsRefresh` true → self-heals). i18n pretranslate is skipped for fallback rows.
  3. **Global-content route resilience** (`_legacy_web/app/api/ai/global-content/route.ts`): if a **usable** row exists for today it is served immediately and any staleness is refreshed in the **background** (throttled, fire-and-forget) instead of blocking/failing the response on regen; **cold-miss writes a fast deterministic `writeStructuralGlobalRow` (no LLM, ~1–2s) and returns it immediately, then triggers background LLM-text refresh** — so the free cold path answers within the 25s client timeout instead of blocking on a ~60s DeepSeek/Gemini call and timing out; a past-day usable row is the last-resort fallback. 503 only when literally nothing usable is producible.
  4. **Free render vs cache decoupled** (`services/dayContentIntegrity.ts`): new `isFreeDayContentRenderable` (base + slogan + short_text + math_level, `long_explanation` optional) is the free render gate, so a fallback row whose non-`§`-structured `long_explanation` the localizer strips still renders (client shows deterministic detail text). `isDayContentCacheable` stays strict (`isDayContentComplete` for free) so a placeholder is **not** cached and self-heals on next open. `useDayContent` free branch uses the renderable gate.
  5. **Copy:** `recommendation.loading` changed from «Обновляем рекомендацию на выбранном языке…» to «Загружаю текст рекомендации на этот день» (RU) + updated EN inline and de/fr/it/es/pt/nl typed overlays + `.sync-meta.json`.
