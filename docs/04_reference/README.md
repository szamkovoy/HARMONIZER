# Reference

`docs/04_reference/` — это методический справочник проекта: формулы, методики, продуктовые модели и другие автономные материалы, которые не зависят от структуры кода.

В отличие от `spec.md` модулей, reference-документы не описывают текущее состояние реализации и не синхронизируются с кодом при рефакторинге. `spec.md` фиксирует runtime-контракт модуля, а reference хранит знания предметной области.

Если reference относится к модулю, в `spec.md` этого модуля добавляется раздел `Справочные материалы` со ссылками на нужные документы.

Правило переноса: материал переносится дословно, без переписывания и интерпретации. Допускается только структурирование, разделение на части и исправление явных опечаток.
