# Индекс стресса Баевского

## 4. Как вычислить индекс стресса Баевского (SI)

Этот индекс показывает, насколько «жестко» мозг управляет сердцем. В стрессе интервалы становятся одинаковыми (сердце стучит как метроном), и индекс растет.

Для расчета нам нужна выборка интервалов за `1–2` минуты (например, `100` ударов).

Переменные формулы:

1. `Mo (Мода)`: Самое частое значение интервала. Если большинство интервалов около `800 ms`, то `Mo = 0.8` (считаем в секундах).
2. `AMo (Амплитуда моды)`: Какая доля (в процентах) всех ударов попала в это самое частое значение. Если из `100` ударов `50` были по `800 ms`, то `AMo = 50`.
3. `MxDMn (Вариационный размах)`: Разница между самым длинным и самым коротким интервалом. Если макс. — `900 ms`, а мин. — `700 ms`, то `0.9 - 0.7 = 0.2`.

Итоговая формула Баевского:

```text
SI = AMo / (2 · Mo · MxDMn)
```

Пример расчета:

```text
SI = 50 / (2 · 0.8 · 0.2)
   = 50 / 0.32
   ≈ 156
```

**Интерпретация:**
- `50–150`: Состояние покоя, норма.
- `150–500`: Психоэмоциональное напряжение.
- `900+`: Сильный стресс, организму тяжело.
