# Brief: Vimeo Asanas Import

Используй этот документ в новом чате, когда задача касается подготовки выгрузки из Vimeo, импорта асан в Supabase, структуры данных асан, ранжирования асан или экрана запуска Vimeo-практики.

## Цель

Импортировать около 200 видеоуроков с асанами из Vimeo в каталог практик без переноса самих видео. В приложении храним metadata и `vimeo_id`, а воспроизведение делаем через Vimeo embed/player на отдельном витке.

## Что нужно получить из Vimeo-инструмента

Минимальный формат списка:

```json
[
  {
    "vimeo_id": "123456789",
    "title": "Название из Vimeo",
    "chakra_ids": [6],
    "recorded_at": "2024-03-12",
    "duration_sec": 1097,
    "quality": 5
  }
]
```

Расширенный формат:

```json
[
  {
    "vimeo_id": "123456789",
    "title": "Аджна практика 18 минут",
    "chakra_ids": [6, 7],
    "primary_chakra_id": 6,
    "recorded_at": "2024-03-12",
    "duration_sec": 1097,
    "quality": 5,
    "description": null,
    "vimeo_url": "https://vimeo.com/123456789",
    "tags": ["аджна", "баланс"],
    "notes": "optional private note"
  }
]
```

## Правила нормализации

- `vimeo_id` обязателен и должен быть уникальным.
- `duration_sec` обязателен для асан, потому что длительность фиксирована длительностью видео.
- `chakra_ids` обязателен и может содержать несколько чакр.
- `primary_chakra_id` желателен, но если его нет, первой чакре из `chakra_ids` можно поставить `is_primary=true`.
- `quality` nullable. Если нет значения, не считать это ошибкой.
- `recorded_at` nullable. Если нет даты, не считать это ошибкой.
- Название можно временно заменить на "Практика 1", "Практика 2", но исходное Vimeo title лучше сохранить в `params.vimeo_title`.

## Маппинг в Supabase

Таблица `practices`:

- `slug`: `asana-vimeo-<vimeo_id>` или стабильный slug из названия;
- `kind`: `yoga`;
- `title`: `{ "ru": "Практика N", "en": "Practice N" }` или локализованное название;
- `description`: `{}` или текст, если появится;
- `default_duration_sec`: `duration_sec`;
- `min_duration_sec`: `duration_sec`;
- `max_duration_sec`: `duration_sec`;
- `params`: `{"source":"vimeo_import","recorded_at":"...","quality":5,"vimeo_title":"...","tags":[...]}`;
- `video_provider`: `vimeo`;
- `video_external_id`: `vimeo_id`;
- `video_url`: если есть;
- `rating`: `quality` или `0`, если quality отсутствует;
- `is_active`: `true`.

Таблица `practice_chakras`:

- по одной строке на каждую чакру;
- `is_primary=true` только для primary;
- `weight=1` для primary, `0.7` для вторичных, если нет более точной логики.

Если решим добавить структурные поля:

- `practices.recorded_at date`;
- `practices.quality smallint check (quality between 1 and 5)`;

тогда `rating` можно оставить универсальным computed-like полем или временно дублировать `quality`.

## Ранжирование асан

Цель: предлагать разнообразные практики, близкие по чакре и времени.

Второй виток selector:

1. Фильтр: `kind='yoga'`.
2. Фильтр: есть связь с нужной чакрой в `practice_chakras`.
3. Фильтр по длительности: target duration +- 15%.
4. Исключить последние 15 завершенных асан пользователя.
5. Сортировать:
   - `quality/rating desc`, null как среднее или как 0, нужно выбрать;
   - `recorded_at asc`, null last;
   - затем стабильный `id`.
6. Если список пустой:
   - расширить допуск длительности;
   - затем игнорировать recent stack;
   - затем предложить ближайшую по длительности практику нужной чакры.

## Экран запуска асаны

Первый виток:

- `app/asana-practice.tsx`;
- принимает `practiceId`;
- загружает metadata;
- показывает название, длительность, чакры, Vimeo id;
- если player не готов, показывает заглушку "Видео-практика будет открыта здесь".

Второй виток:

- встроить Vimeo player;
- проверить iOS/Android поведение;
- добавить начало/завершение `practice_sessions`;
- сохранить duration по фактическому завершению или по длительности видео.

## Вопросы перед импортом

- Названия показывать как "Практика N" или использовать исходные Vimeo title?
- Quality null сортировать как 0, как 3 или null last?
- Если в названии Vimeo есть несколько чакр, кто определяет `primary_chakra_id`: Vimeo-инструмент или импорт?
- Нужно ли сразу делать экран player или сначала только каталог metadata?

## Критерии приемки первого витка

- Формат импорта согласован.
- Импорт не ломается на null `quality` и null `recorded_at`.
- Одна практика может быть связана с несколькими чакрами.
- В каталоге появляются асаны с длительностью и чакрами.
- Есть технический путь открыть карточку/экран асаны по `practiceId`.
