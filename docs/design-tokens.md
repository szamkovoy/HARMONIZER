# Design tokens (каталог оформления)

Единый реестр оформительских параметров приложения. Источник правды — `modules/ui/theme.ts`.
Этот документ — шпаргалка: какие у нас текстовые стили, цвета и палитры, чтобы при
коммуникации можно было коротко сказать «это `sectionTitle` светлой темы» и знать, о чём речь.

## Палитры

Две подключаемые схемы, выбираются провайдером:

| Имя | Где применяем |
| --- | --- |
| `dark` | Экраны биофидбэка/мандалы (чёрный фон, светлый текст) — по умолчанию. |
| `light` | Каталоги/настройки/списки практик (светлый фон, тёмный текст). |

Цветовые токены (смысловые, не привязанные к оттенку) идентичны между палитрами:

| Токен | Смысл |
| --- | --- |
| `screenBg` | Базовый фон экрана |
| `surface` / `surfaceElevated` | Карточки (панели), модалки |
| `surfaceBorder` | Рамки у `surface` |
| `accent` / `accentOnText` | Акцентный цвет (прогресс, кольцо таймера, активные состояния). `accentOnText` — контрастный текст поверх акцента (на primary-кнопке). |
| `textPrimary` / `textMuted` / `textFaint` | Три ступени текста (от основного к третьестепенному) |
| `warning` / `danger` | Цвета предупреждений и ошибок |
| `controlButtonBg` / `controlButtonPressedBg` | Круглые/иконочные кнопки (крестик, ±) |
| `buttonPrimaryBg` / `buttonPrimaryFg` | Primary-кнопки |
| `buttonSecondaryBorder` / `buttonSecondaryFg` | Secondary-кнопки (обводка) |
| `modalBackdrop` | Фон за модалкой |

## Типографика

Размер и насыщенность шрифта **не зависят от палитры**. Цвет берётся из палитры
через тон (`tone`): `primary | muted | faint | warning | danger | accent | accentOn`.

В коде текст ставится через `AppText`:

```tsx
<AppText variant="screenTitle" tone="primary">Активация пульсометра</AppText>
```

Список поддерживаемых стилей (варианты типографики):

| Вариант (`variant`) | Где использовать | Подходящий «человеческий» ярлык |
| --- | --- | --- |
| `screenTitle` | Заголовок окна/экрана (например, «Активация пульсометра») | **Заголовок** |
| `screenHint` | Основной текст инструкции под заголовком экрана | **Основной текст** |
| `dialogTitle` | Заголовок модалки («Завершить практику?», «Пульс не распознан») | **Заголовок** (в модалке) |
| `dialogBody` | Основной текст в модалке (белый поверх тёмной темы) | **Основной текст** |
| `sectionTitle` | Название практики во всплывающей панели, названия секций | **Подзаголовок** |
| `statPillLabel` | Подзаголовок под названием (санскрит), метки пилюль | **Мелкий подзаголовок** |
| `technicalCaption` | Мелкий дополнительный текст (отладочные метрики, PPG-баннеры) | **Мелкий текст** |
| `bannerMessage` | Короткие сообщения-баннеры | **Мелкий текст (предупреждения)** |
| `inlineStatus` | Статусные строки в окнах (например, «Ожидание устойчивого сигнала…») | **Основной текст (status)** |
| `buttonLabel` | Надписи на кнопках (primary и secondary) | **Кнопки** |
| `numericLarge` | Крупные цифры/фазы: «ВДОХ/ВЫДОХ/ЗАДЕРЖКА», таймер активации | **Крупный** |

Семейство шрифта — сейчас системное (`fontFamily: undefined`). Чтобы задать кастомный
шрифт проекта — переопределяется в теме через провайдер.

## Радиусы и отступы

| Токен | Значение | Где использовать |
| --- | --- | --- |
| `radius.xs/sm/md/lg` | 4 / 8 / 12 / 20 | Кнопки, пилюли, карточки |
| `radius.pill` | 999 | Круглые/капсульные элементы (иконочные кнопки, highlighted pill) |
| `spacing.xs..xl` | 4/8/12/16/24 | Отступы и пробелы |

## Поверхностные карточки (`SURFACE_CARD`)

Единый каркас белых блоков на Home / Day / Profile. Константа — `modules/ui/surfaceCard.ts`, дублируется в `theme.surfaceCard`.

| Поле | Значение | Смысл |
| --- | --- | --- |
| `padding` | 18 | Отступ от верхней границы карточки до заголовка блока (`sectionTitle`) |
| `gap` | 14 | Вертикальный зазор между дочерними элементами внутри карточки |
| `borderRadius` | 24 | Скругление углов |
| `borderWidth` | 1 | Толщина рамки |

Импорт: `import { SURFACE_CARD } from "@/modules/ui/surfaceCard"` или `useTheme().surfaceCard`.

## Правила подключения

1. В корне экрана оборачиваем в `<ThemeProvider value={buildTheme("dark")}>` или `"light"`.
2. Компоненты читают цвет через `useTheme().colors.xxx`.
3. Текст пишем через `<AppText variant="…" tone="…">`.
4. Кнопки — через `<AppButton variant="primary" | "secondary">`.
5. Модалки — через `<AppDialog actionsLayout="row"|"column">`.

## Как добавить новый стиль текста

1. Добавить поле в `TypographyTokens` в `modules/ui/theme.ts`.
2. Прописать token в `defaultTheme.typography`.
3. Дополнить таблицу выше — чтобы при созвоне можно было на него сослаться.

## Рекомендация по именованию в коммуникации

Чтобы договориться об изменениях быстрее — ссылаемся на «роль», не на цвет:

- «Подзаголовок в панели дыхания должен быть чуть меньше» → `statPillLabel`.
- «Кнопки в диалоге цветнее» → `buttonPrimaryBg` / `buttonSecondaryBorder`.
- «Текст под таймером активации» → `inlineStatus`.
