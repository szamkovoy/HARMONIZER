# Перенос интенсивов — рабочий план

Задание Сергея от 19.11.2026. Это план, а не описание готового механизма.

## Подтверждено

- Существующая инструкция практикумов и механизм накопительных курсов сохраняются.
- Семь интенсивов, 30 видео в порядке списка уроков; 29 уникальных советов из писем + общий текст «Что дальше?» на день 30.
- Общий календарь курсов: первая выдача сразу; второй день в следующую местную полночь, при старте с 18:00 — через одну полночь; далее ежедневная смена.
- Только текущий урок, без архива и стрелок; после последнего дня доступ закрывается. Несколько покупок могут идти одновременно.
- Два письма: вводное сразу; заключительное в 07:00 местного дня 30-го урока. Показ в автоцепочке должен явно обозначать день 30, а не ошибочный фиксированный срок 30 суток.
- Авторские тексты писем **не исправлять**, включая фразу об ежедневных письмах (ответ Сергея 19.11). Заголовки пунктов 1–7 — жирные; пустые строки сохранять.
- Видео: существующий Vimeo-плеер и выбор дорожки как у асан (ru для RU, en для остальных). Остальные курсы остаются русскими.
- Тексты/письма интенсива — восемь локалей; повторяющиеся абзацы переводить один раз и переиспользовать.
- Отдельный тест: оба письма на sergei@zamkovoi.yoga, стрелки для 30 уроков. После «проверил» — **обычный календарь с первого дня**, без повторной отправки писем (ответ Сергея 19.11).
